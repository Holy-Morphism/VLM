# Fine-Tuning VLM and Demo App

This repository contains a notebook for fine-tuning the BLIP-2 vision-language model with LoRA on the Flickr8k dataset for image captioning and a demo for interacting with the finetuned model.

Here is a [blog](https://medium.com/@ranaadeeltahir/fine-tuning-blip-2-with-lora-on-the-flickr8k-dataset-for-image-captioning-829454a825c7) explaining how I fine-tuned this VLM, you can also read about this on my website [Fine-Tuning BLIP-2 with LoRA on the Flickr8k Dataset for Image Captioning](https://ranaadeeltahir.me/blog/fine-tuning-blip-2-lora-flickr8k-image-captioning)
